Step 1

Connect to GitHub

A token lets this page publish updates straight to the repo so every friend sees the same live scoreboard.

How do I get a token?
  1. Go to github.com/settings/personal-access-tokens/new (fine-grained tokens).
  2. Name it something like nfl-pickem-admin.
  3. Under Repository access, choose Only select repositories and pick robbycorrs23/nfl-pickem-gh.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Generate the token and paste it below. It's stored only in this browser (localStorage) and only ever sent to GitHub's API.
